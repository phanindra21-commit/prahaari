# PRAHARI demo video — shot list (about 2:30)

Before recording: `npm run demo:reset`, `npm run dev`, open http://localhost:5173
in Chrome at 1920x1080, close other tabs and notifications.

Record with Windows Game Bar (Win+G, then Record) or OBS. Record the screen in
one take per scene, silent. Then run `make-voiceover.ps1` and put each
`voiceover/sceneNN.wav` over the matching clip in Clipchamp (free) or CapCut.
Trim or slow the clip so it lasts as long as the narration.

| Scene | On screen                                                                 |
| ----- | ------------------------------------------------------------------------- |
| 1     | Title slide or the login page; keep still                                 |
| 2     | Log in as the District Officer demo account                               |
| 3     | Map for Wayanad; slowly zoom to the hazard cells and habitation dots      |
| 4     | Click one habitation; show vulnerability, safe/unsafe and top factors     |
| 5     | Priority worklist; open a recommendation; show site, capacity and route   |
| 6     | Click Approve, type a justification, submit                               |
| 7     | Show the audit log and the integrity badge                                |
| 8     | Scenario simulator briefly, then the /deployment page                     |
| 9     | Return to the title slide or map; hold still                              |

Tip: record the screen after listening to each scene's WAV once, so your
mouse moves match the words. Say nothing about live data; it is synthetic.
